# HSU24 Mitarbeiter-App (Expo)

Native Mitarbeiter-App von HSU24, einer Zeitarbeitsfirma. Dolmetschen ist nur eine von vielen Leistungen. Zuerst lesen: `docs/SPAR-ANLEITUNG.md` (kurz, spart Credits), `docs/FUNKTIONSLISTE.md` (Aufgabenliste), `docs/design-mitarbeiter-app.md`, `docs/ARCHITEKTUR.md`, `EMERGENT_HANDOFF.md`.

```
npm install
npx expo start --lan
npm run check      # Typen, Lint, Tests
```

Eine App, Expo Router, Revolut-Design, klassisch weiß. Ohne Backend-Konfiguration läuft sie im markierten Demo-Modus (`EXPO_PUBLIC_DATA_MODE`, `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_ANON_KEY`).
